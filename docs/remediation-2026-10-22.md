## Verification performed

- TypeScript, formatting, all **45 unit tests across seven files**, production builds and whitespace checks pass.
- Isolated `/tmp` install used the reviewed lockfile with lifecycle scripts disabled. Clean unit/build/artifact checks passed using official Node **22.23.4**, downloaded only to `/tmp` and checked against the official SHA-256. System Node was not changed. The first clean fixture omitted root LICENSE; that fixture error was corrected before the successful artifact check.
- Installed/locked dependency notices: **141 production packages** with full texts; all requested key notices and OFL files are in the build. No public source maps or private-key markers found by the limited artifact check. This is not a comprehensive secret or provenance scanner.
- `npm audit --json --ignore-scripts`: zero reported advisories, audit report v2, 225 locked entries. The isolated npm-ci installed-platform audit also reported zero. No dependency vulnerability was invented and no application dependency version was changed to pretend a clean scan.
- Built-site local response verification checks homepage, Apache license, dependency notices and security.txt against CSP/nosniff/anti-framing/referrer policies. The actual production host has not been requested or scanned.
- Local headless Chrome suites passed: security_browser.py, editing_browser.py, session_browser.py, header_browser.py, landing_browser.py, browser.py, oss_landing_browser.py and drop_browser.py. Tests use isolated profiles and temporary synthetic files, not existing user browser data. The security suite blocks external page requests and checks no page/CSP errors, with a >160-KiB ZIP to exercise the compression worker.
- During verification, strict CSP exposed inlined font URLs; font-src was corrected narrowly to include data fonts. A Playwright expression needing eval was replaced with a function in the test harness; CSP was not loosened to allow unsafe-eval. Initial checkbox timing and stale test assumptions were corrected and rerun.
- Desktop and phone landing/editor screenshots were reviewed. No real OS permission dialog, manual screen reader, native mobile device, hosted deployment, legal compliance or historical production rollback was verified.

## Release decision boundary

These repository fixes reduce the reproduced single-tab data-loss/privacy/resource risks and supply missing release artifacts. **They are not a public-launch signoff.** AUD-001 remains deliberately excluded. The direct-write OS-race limit, license supplement/provenance review, actual host isolation/headers/TLS, CI protection/monitoring and operator legal facts still need explicit review before a sensitive-data public release. Refer to docs/release-runbook.md and docs/legal/launch-review.md for concrete next steps; do not mark those external gates complete from local test success.
